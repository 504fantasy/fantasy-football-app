Commissioner Guide
Everything a commissioner can control on 504 Fantasy
🏆 Playoff Challenge
League Setup
Create the league, set picks per team, configure the pick timer for the live draft, and set the entry fee and payment deadline. An 8-character invite code is generated automatically — share it with your group to let them join.
Draft Order
Before the draft, set the Round 1 pick order from the Settings tab. Use the Randomize button to shuffle teams automatically, or manually assign each pick slot using the dropdowns. The snake draft reverses this order each round.
Running the Draft
Start the snake draft when everyone is ready. During the draft you can pause picks at any time using the Pause button — no picks can be made while paused. You can also rewind the last pick if a mistake is made, or fully reset the draft to start over. The pick timer auto-picks from the team's queue if time expires.
Pony & Multiplier Window
Set the date and time that the pony pick window closes. After that time, all unrevealed pony picks are automatically revealed and no new multiplier changes are allowed. You can lock it manually at any time from the manage panel.
Entering Scores
The scoring engine calculates points, applies multipliers, and updates the leaderboard automatically. You can override any player's score with a custom point total if needed.
Payment Tracking
Mark teams as paid or unpaid. Set an entry fee and Venmo handle so players know where to send money. Teams that haven't paid by the deadline can be restricted from making picks.
Managing Players
The player pool is automatically seeded from NFL rosters when the league is created. You can manually add players if someone is missing from the database.
Audit Log
Every action in the league — picks, score entries, multiplier changes — is logged and downloadable as a CSV. Useful for resolving disputes.
🎯 Survivor League
League Setup
Configure roster depth per position — e.g. start 1 QB, 2 RBs, 3 WRs, 1 TE, 1 DST, 1 K each week. Set the entry fee, payment deadline, and Venmo handle. The league runs Weeks 1–18 of the regular season.
Lineup Locking
No manual lock needed — players lock automatically at their individual game kickoff time. Once a player's game starts, they can't be swapped. Lineups stay hidden from everyone, including the commissioner, until the first game of the week kicks off — keeping things fair for all teams.
Week Advancement
Weeks advance automatically once all games for the current week have finished. The commissioner can also manually advance the week from the manage panel if needed.
Entering Scores
The scoring engine calculates totals and updates the season leaderboard automatically. Score overrides are available for any player.
Payment Tracking
Same as the Playoff Challenge — mark teams paid/unpaid, set entry fee and Venmo handle, restrict unpaid teams after the deadline.
Managing Players
The player pool is automatically seeded from NFL rosters when the league is created. You can manually add players if someone is missing from the database.
Audit Log
Every action in the league — lineup submissions, score entries, week advances — is logged. Useful for resolving disputes.
